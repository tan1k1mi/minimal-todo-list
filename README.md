# Список задач

Минималистичный To-Do List на чистых HTML, CSS и JavaScript.

**Демо:** https://tan1k1mi.github.io/minimal-todo-list/

## Возможности

- добавление задач;
- выбор дня через компактную недельную ленту от текущего дня до того же дня следующей недели;
- разделы «Сегодня» и «Предстоящие» с группировкой по датам;
- отметка выполненных задач;
- удаление задач;
- сохранение данных в `localStorage`.

## Запуск

Откройте `dist/index.html` в браузере или запустите любой статический сервер:

```bash
python3 -m http.server 8000 -d dist
```

После этого сайт будет доступен по адресу `http://localhost:8000`.
